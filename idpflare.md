# IDPFlare Deployment & Setup Guide

This guide describes how to deploy and configure **IDPFlare** (from [lukeschafer/idpflare-luke](https://github.com/lukeschafer/idpflare-luke)) as the identity provider for your microSaaS application.

---

## Quick Setup Commands

Run the following commands in your IDPFlare repository directory:

```bash
# 1. Clone & Install
git clone https://github.com/lukeschafer/idpflare-luke.git idpflare
cd idpflare
npm install

# 2. Create Cloudflare Resources
wrangler d1 create idpflare-db
wrangler kv namespace create SESSIONS
wrangler kv namespace create RATE_LIMIT

# 3. Generate Encryption Keys
node scripts/generate-keys.js

# 4. Apply Database Migrations
npm run db:migrate:prod

# 5. Deploy IDPFlare Worker
npm run deploy
```

## Linking IDPFlare with this MicroSaaS App

1. Register an OIDC Client in IDPFlare for your microSaaS application:
   - **Client ID**: Generated by IDPFlare administration panel or CLI.
   - **Redirect URI**: `https://<your-app-domain>/auth/callback` (or `http://localhost:5173/auth/callback` for local dev).
   - **Allowed Grant Types**: `authorization_code`, `refresh_token`.
   - **PKCE**: Enabled (S256 code challenge).
2. Set the `OIDC_CLIENT_ID` and `OIDC_ISSUER_URL` in `src/config/branding.ts`.
